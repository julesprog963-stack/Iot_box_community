IoT Box Community

Odoo 17 Community module for IoT boxes, devices and print jobs, designed to work with an external Python agent on Windows or Linux.

What this module provides

  • IoT Box records with token-based agent authentication
  • Device management for ticket, label and standard printers
  • IoT job queue with job result tracking
  • Heartbeat monitoring and online status handling
  • Automatic device synchronization from the external agent

Supported workflow

  • Create an IoT Box in Odoo and generate its token
  • Install the external IoT agent on Windows or Linux
  • Configure agent URL, optional DB and token
  • Auto-detect local printers and sync them to Odoo
  • Execute test print jobs and operational jobs

REST API endpoints

  • /iot/api/v1/register
  • /iot/api/v1/heartbeat
  • /iot/api/v1/jobs/poll
  • /iot/api/v1/jobs/result
  • /iot/api/v1/config
  • /iot/api/v1/devices/sync

Important note

This repository contains the Odoo module only. The external IoT agent is deployed separately and communicates with Odoo through outgoing HTTP requests.
