Se requiere Community IoT Agent v0.4.0
Este addon es el centro de control en Odoo. El agente se instala por separado en el equipo local y se comunica mediante el token de la caja.

IoT Box Community for Odoo 19

Manage boxes, devices, heartbeats and print jobs from Odoo Community while the separately installed local agent connects to the printers.

Boxes and devices

Create online boxes, register capabilities and review discovered peripherals.

Jobs and status

Track pending, completed and failed work with attempts and result status.

Separate agent boundary

Agent connection settings and secrets remain on the local host; the addon never bundles, downloads or executes agent code.

Agent and device workflow

  1. Create the box: generate a token in Odoo; it remains masked in the interface.
  2. Install the agent: run Community IoT Agent v0.4.0 as a separate Linux service or container on the host that can reach the devices.
  3. Configure locally: open the local agent portal, configure the Odoo URL, database and token, and keep these secrets on the agent host.
  4. Verify the heartbeat: Odoo receives status, capability information and device synchronization, then exposes jobs for polling and result reporting.

Linux/CUPS: the standard-printer path uses the local CUPS queue and the pdf_print_v1 capability. Use Test connection and the printer's test page only for a defined test document. Windows is outside the evidence represented by this Odoo 19 publication branch.

Local portal: the agent portal is local to the agent host; its service configuration and credentials are not stored in this addon repository.

Compatibility and boundaries

Odoo 19 Community · Private Odoo.sh projects · On-premise deployments · Requires Community IoT Agent v0.4.0.

The addon manages the Odoo data and API boundary. It does not install, download or execute the agent, and it does not store the agent's local service configuration.

Descripción en español

Administre cajas IoT, dispositivos, latidos y trabajos de impresión desde Odoo Community 19. Community IoT Agent v0.4.0 se instala por separado en el equipo local y conecta las impresoras mediante CUPS.

Genere el token en Odoo, configúrelo únicamente en el agente local y revise la sincronización de capacidades, dispositivos y trabajos. El addon no descarga ni ejecuta código del agente.
